# Bouncers
Create bouncing balls that collide with the walls of the screen and with each other! You can also summon a special bouncer that always stays at the average coordinate position of all other bouncers on screen. This one doesn't have colliding physics, though.

[Try it out here!](https://the-arctic-winter-7.github.io/bouncers/)

### Controls

Press A (X for mGBA emulator) to summon a bouncer.<br>
Press B (Z for mGBA emulator) to summon a special bouncer that follows the average position of all other bouncers.
